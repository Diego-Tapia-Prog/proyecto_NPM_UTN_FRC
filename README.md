# 🚀 Proyecto NPM: Desafío 1

Este proyecto es una ejercitación integradora para la materia **Desarrollo de Software**. Se centra en la configuración de un entorno de trabajo profesional utilizando **Node.js** y **npm**, integrando herramientas de calidad de código y generación de datos aleatorios[cite: 1].

---

## 📋 Requisitos

Para ejecutar este proyecto, asegúrate de tener instalado:
* **Node.js**: Versión **24.0.0 o superior**[cite: 1].
* **npm**: (Viene incluido con Node.js).

---

## ⚙️ Instalación

Para preparar el entorno y descargar las dependencias necesarias, ejecuta uno de los siguientes comandos en tu terminal:

```bash
# Opción 1
npm install

# Opción 2 (abreviada)
npm i

```
---
**Importante**: Este proceso generará la carpeta `node_modules` y utilizará el archivo `package-lock.json` para asegurar la consistencia en las versiones de las librerías.

---

## 🚀 Uso

Puedes iniciar la aplicación utilizando los scripts configurados en el `package.json`

```bash
# Opción 1
npm start

# Opción 2 
npm run start

```

---

## 🛠️ Script disponibles
A continuación, se detallan los comandos disponibles para el desarrollo y despliegue:

|    Comando    |         Descripcion          |
|---------------|------------------------------|
| `npm start`   | Ejecuta la aplicación principal (index.js).        |
| `npm run dev` | Inicia el entorno de desarrollo. | 
| `npm test`    | Ejecuta las pruebas unitarias del proyecto.           |

## 📂 Estructura del Proyecto

```
.
```
