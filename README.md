# Proyecto NPM
Este es mi proyecto enfocado en utilizar node y npm junto a unas dependencias de eslit y seedrandom

## Requisistos

- [Node.js] (https://nodejs.org/) (v24 o superior)
- npm

## Instalacion

Pueden haber dos formas de hacerlo 

1º
```bash
npm install
```

2º
```bash
npm i
```

## Uso

Pueden haber dos formas de hacerlo 

1º
```bash
npm start
```

2º
```bash
npm run start
```

## Script disponibles

|---------------|------------------------------|
|    Comando    |         Descripcion          |
|---------------|------------------------------|
| `npm start`   | Iniciar la aplicación        |
| `npm run dev` | Iniciar en modo desarrolador | 
| `npm test`    | Ejecuta los test             |
